# Bento Grid

A modern, responsive bento-style layout built with HTML and CSS. This project showcases a clean card-based interface with a polished, lightweight design that can be adapted for portfolios, dashboards, product showcases, or landing pages.

## Preview

![Bento Grid Preview](./preview.jpg)

## Overview

This repository contains a front-end design implementation inspired by the Bento Grid layout trend: compact, tidy, card-based sections arranged in a visually balanced grid. The goal was to create a refined and responsive page that feels clean, premium, and easy to customize.

## Features

- Responsive layout for desktop and mobile devices
- Bento-style card design with structured visual hierarchy
- Clean modern aesthetic using a minimal color palette
- Easy to extend for portfolios, dashboards, or product pages
- Built using simple front-end technologies

- CSS

## Run Locally

You can open the project directly in the browser:

```bash
open index.html
```

Or serve it locally with a simple web server:

```bash
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```

## Customization

Edit the following files to tailor the layout and style to your needs:

- `index.html` — structure and content
- `style.css` — colors, spacing, layout, and responsiveness
- `script.js` — interactions and dynamic behavior
