# Bento Grid

A lightweight, modern grid-based landing page or gallery layout built with HTML and CSS.

## Overview
This project showcases a Bento-style card layout with a clean, contemporary UI. It is designed to be simple, responsive, and easy to customize.

## Features
- Responsive Bento-style layout
- Clean and modern visual design
- Easy to adapt for portfolios, dashboards, or product showcases
- Built using plain HTML/CSS for quick setup

## Project Structure
```bash
.
├── index.html
├── style.css
├── script.js (if used)
└── assets/
```

## Run locally
You can view the project by opening `index.html` directly in a browser.

If you want to serve it locally with a small web server:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Customize
Edit the HTML structure in `index.html` and the styling in `style.css` to change the layout, colors, spacing, and content.
